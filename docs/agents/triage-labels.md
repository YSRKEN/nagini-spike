# Triage Labels

スキルは、triage の5つの標準の役割で話す。このファイルは、その役割をこのリポジトリの issue tracker で実際に使う文字列に対応させる。local markdown では、issue ファイルの `Status:` 行にこの文字列を書く。

| mattpocock/skills のラベル | このリポジトリのラベル | 意味                                         |
| -------------------------- | ---------------------- | -------------------------------------------- |
| `needs-triage`             | `needs-triage`         | 管理者がこの issue を評価する必要がある      |
| `needs-info`               | `needs-info`           | 報告者からの追加情報を待っている             |
| `ready-for-agent`          | `ready-for-agent`      | 仕様が固まっていて、無人のエージェントに渡せる |
| `ready-for-human`          | `ready-for-human`      | 人が実装する必要がある                       |
| `wontfix`                  | `wontfix`              | 対応しない                                   |

スキルが役割に触れたとき（例:「AFK-ready の triage ラベルを付ける」）は、この表の対応する文字列を使う。

実際に使う語彙に合わせて、右から2列目を書き換えてよい。
