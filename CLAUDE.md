## Agent skills

### Issue tracker

issue と仕様は、`.scratch/<feature>/` の下に local markdown のファイルとして置く。`docs/agents/issue-tracker.md` を参照。

### Triage labels

既定の5つの役割名（needs-triage・needs-info・ready-for-agent・ready-for-human・wontfix）をそのまま使う。`docs/agents/triage-labels.md` を参照。

### Domain docs

single-context。リポジトリのルートに `CONTEXT.md` と `docs/adr/` を1組置く。`docs/agents/domain.md` を参照。
